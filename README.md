死了么 (Sileme)

项目简介

"死了么"是一个基于Java Swing开发的个人敏感信息删除系统，旨在帮助用户在不幸离世后，安全地处理个人数字资产和隐私数据。程序通过身份验证机制，确保只有授权的接管者能够清理用户的敏感信息。

功能特点

🔐 安全验证机制

· 双重身份验证：原用户使用确认码验证，接管者通过姓名验证
· 多次确认：死亡确认需要3次重复确认，防止误操作
· 确认码尝试次数限制：原用户有20次尝试机会，防止暴力破解

📁 数据管理

· 选择性清理：可配置需要删除的特定文件夹
· 浏览器记录清除：自动清理Edge浏览器历史数据
· 全面销毁：在极端情况下可执行全面数据销毁

🛡️ 安全保护

· 防关闭保护：非正常关闭程序将触发系统崩溃
· 身份验证：严格的接管者身份验证流程
· 配置持久化：所有配置序列化保存，确保设置持久有效

系统要求

· 操作系统：Windows 7及以上（仅支持Windows系统）
· Java环境：Java 11或更高版本
· 必须权限：administrator


使用指南

首次配置

1. 启动程序：首次运行将进入配置向导
2. 设置个人信息：输入原用户姓名
3. 添加接管者：指定可信赖的接管者名单
4. 配置消息：设置死亡确认后显示的消息
5. 选择清理目录：指定需要删除的文件夹
6. 选择可执行文件：在清理文件前执行的文件
7. 设置确认码：创建用于证明存活的密码

正常使用流程

1. 系统启动：程序在登录后自动运行
2. 身份选择：
   · 接管者：点击"死了"按钮，验证身份后执行数据清理
   · 原用户：点击"没死"按钮，输入确认码证明存活

特殊情况处理
· 尝试次数耗尽：连续输错确认码将触发数据销毁和系统崩溃
· 非法关闭：强制关闭程序将导致系统崩溃

数据清理内容

浏览器数据清理

· 缓存文件 (Cache)
· 浏览历史 (History)
· Cookie数据
· 登录信息
· 网站数据

文件清理

· 用户指定的文件夹
· 文档、下载、桌面等常用目录
· 临时文件

安全警告

⚠️ 重要注意事项：

1. 数据不可恢复：清理操作不可逆，请谨慎配置
2. 系统稳定性：非法关闭可能导致系统崩溃
3. 备份重要数据：使用前请备份重要文件，或在虚拟机中使用
4. 测试环境验证：建议在测试环境中验证配置
